QAbank 随机刷题程序
===================

运行方式
--------

在本文件夹打开终端，运行：

```bash
python main.py
```

题库识别
--------

程序启动时会自动扫描当前文件夹及子文件夹中的 `.xlsx`、`.csv`、`.txt`、`.md` 文件，并把文件名或一级文件夹名识别为学科。

Excel/CSV 推荐列名：

- `题目`
- `类型` 或 `题型`
- `参考答案`、`正确答案` 或 `答案`
- 可选：`A`、`B`、`C`、`D`、`E` 等选项列

文本题库支持类似格式：

```text
1. 药剂学是什么？
A. ...
B. ...
答案：A
```

没有答案的题目会被跳过。选择题会自动用勾选框作答，名词解释和问答题会显示文本框并提供参考答案。
