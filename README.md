# 个人分享网站

这是一个用于整理学习、科研和生活内容的个人网站项目。网页部分位于 `web/` 目录，包含首页、浙江大学课程整理、实验流程、留学申请与使用说明等页面。

项目中也包含 `QAbank/` 随机刷题小程序，可以自动扫描题库文件并按学科、题型随机出题，适合课程复习使用。

主要内容：

- `web/`：静态个人网站页面与样式、脚本、图片和音乐资源。
- `QAbank/`：基于 Python/Tkinter 的题库识别与随机刷题程序。
- `course_materials/`：课程相关材料整理。

网站整体偏向个人学习记录和资料索引，内容会随课程、实验和个人整理进度持续更新。

# Personal Sharing Website

This project is a personal website for organizing study notes, research-related materials, and everyday records. The website lives in the `web/` directory and includes the home page, Zhejiang University course notes, lab protocols, study-abroad pages, and usage instructions.

The repository also includes `QAbank/`, a small random quiz application. It scans question-bank files automatically and generates questions by subject and question type, making it useful for course review.

Main contents:

- `web/`: Static website pages, styles, scripts, images, and music assets.
- `QAbank/`: A Python/Tkinter app for recognizing question banks and practicing random questions.
- `course_materials/`: Organized course-related materials.

The site is mainly a personal learning record and resource index. Its content will continue to be updated as courses, experiments, and personal notes are organized.
